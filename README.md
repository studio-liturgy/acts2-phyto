# phyto

A free, open source presentation tool for small worship gatherings.

phyto is built to help keep our times of worship together simple, focused, and organized.
It was created out of a real need in a small house church setting and shared freely in the hope that it can bless other churches, pastors, and communities too.

## What it does

- Create sets from songs, Bible verses, and PNG slides.
- Organize sets into gatherings.
- Run individual sets or full gatherings live.
- Manage everything in a clear, organized way.
- Adjust output templates to suit your setup.
- More functionality to come!

## Why phyto exists

phyto started as a tool for my local church.
In smaller gatherings, we're all wearing multiple hats: the person running slides is often also helping with kids, welcoming people, etc.
I wanted to build something simple that makes presenting just a bit easier — especially for churches, home groups, and worship gatherings with little or no budget.

## Features

- Free and open source.
- Built with Lovable.
- Use it online at [phyto.live](https://phyto.live/).
- Files live on the computer for now.
- Custom output templates.
- Simple workflow for preparing and presenting sets.
